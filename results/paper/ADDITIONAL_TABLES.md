# Additional tables

Tables computed for the paper that are not among the Supplementary Tables S1-S45 (`SUPPLEMENTARY_TABLES.md`). They are not numbered. Generated by `src/supplementary_tables.py` from stored results; nothing is refitted. Each table lists its source file; the source files hold the full tables. Abbreviations: FM = TimesFM 2.5 + MinT (W from the model's own one-step errors); STAT = ETS + MinT; main window = target months to 2025-12 without 2025-09; weighted = 2022 per-day emission weights within one level; scaled metrics divide by the in-sample seasonal-naive MAE at the origin; MASE, sCRPS and Winkler scores are scaled. Every probabilistic table uses exactly reconciled non-negative samples. The test at origin 2026-06 scores the intervals delivered with the final forecasts (data file S1; ACI state extended with the calibration origins).
